# PocketSmart AI - Your Smart Budget Buddy

PocketSmart AI is a smart budget planner for Home, Party, and Jewelry.

## Features
- Home Planner: Plan your home budget with room selection
- Party Planner: Estimate party expenses
- Jewelry Planner: Calculate jewelry budget

## Tech Stack
- Python (FastAPI)
- HTML, CSS, JavaScript
- Uvicorn
